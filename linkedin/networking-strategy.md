Professional networking system for building connections with US technical
recruiters, SaaS founders, engineers, and engineering managers.

### Networking rules for requests

- 200-300 characters maximum
- Personalize with specific reference to their content
- Always mention n8n + Node.js (positioning consistency)
- Include Chicago location when relevant
- No job requests, no service pitches, no outcome promises
- Maximum 5-10 requests/day

## Engagement System

### Pre-connection flow

```
Find relevant profile
        ↓
Review recent posts/activity
        ↓
Find 1 post to comment on meaningfully
        ↓
Write comment adding technical perspective
        ↓
Wait 24-48h for engagement
        ↓
Send connection request referencing the conversation
```

### Comment framework

**DO — Add technical perspective:**
- "In my lead qualification project, I handled [similar issue] by [approach]."
- "I've found that combining [X] with [Y] improves reliability around [use case]."
- "How did you handle [edge case]? I solved it by [approach] in my project."

**DON'T:**
- "Great post!" — zero value
- "Thanks for sharing!" — generic
- Self-promotion in comments

### Weekly engagement cadence

| Activity | Frequency | Time |
|----------|-----------|------|
| Feed scan | Daily | 10-15 min |
| Meaningful comments | 3-5/week | 5 min each |
| Connection requests | 5-10/week | 2 min each |
| Reply to messages | As received | — |

### Inbound message response

- Respond within 24h
- Thank them for connecting
- If asked about work: share portfolio reference, no pitches
- If asked about availability: open to connecting with teams in AI automation
- Never promise timelines, quote rates, or send unsolicited proposals

## Networking Rules

### Do's
- Personalize every connection request
- Add value in comments before connecting
- Reference specific projects when relevant
- Keep conversations professional and technical
- Respond to messages within 24h

### Don'ts
- Mass requests without personalization
- Pitch services in first message
- Ask for jobs directly
- Promise outcomes or timelines
- Engage in non-technical debates

### Content sharing rules
- Share portfolio projects in DMs only when relevant
- Never share client data or private repos
- Never claim results not documented in portfolio

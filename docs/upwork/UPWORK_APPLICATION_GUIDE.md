## Application sequence

1. Update the title, headline, and About copy.
2. Add only skills supported by that platform, preserving the listed priority.
3. Add the four portfolio entries in the source order.
4. Confirm every field reflects the current source and contains no metrics, client names, certifications, or outcomes not supported by the repository.
5. Stop immediately before the platform's final Save, Publish, Update Profile, Submit, or Activate action.

## Validation checklist

- [ ] Uses **AI Automation Developer — n8n, AI Agents & CRM Workflows** as the professional identity.
- [ ] Uses **LLM orchestration** rather than claiming a specific LLM provider where the platform does not require it.
- [ ] Describes human approval and handoff accurately; does not claim fully autonomous operation.
- [ ] Lists only stack items documented in the current project portfolio.
- [ ] Does not introduce clients, metrics, certifications, or commercial results.
- [ ] Final external action has not been triggered.
